What this is

ecoPrimals is a scientific computing system I designed and built on hardware I own. It takes a published paper, rebuilds the computation from the methods section and the original data, compares the rebuilt numbers with the published ones, and packages the result as a single program that anyone can run and that reports its own pass or fail.

It is written in Rust and runs on eleven machines linked by an encrypted network that is part of the project. It needs no cloud account and no vendor-specific graphics toolkit. All of it is open source under AGPL-3.0.

I am looking for research-computing and data roles, and for contract work: rebuilding a lab's ageing pipeline into something reproducible, reproducing a paper, or setting up computing a group owns outright.

Three working systems

tideGlass drug discovery

Task set by Andrea Gonzales, Pharmacology & Toxicology, Michigan State University (June 2026). Original platform: GPS, Bin Chen Lab, MSU — published in Cell, 2026.

The problem
GPS predicts how a compound changes gene expression from its chemical structure alone, then searches compound libraries for ones that reverse a disease's expression signature. Behind it sit more than ten years of research code: Python 2, pinned dependencies, a web portal. The science is sound; the software is hard to hand to anyone else.
What I built
I traced the work back twenty years through its papers (Connectivity Map 2006, LINCS, RGES 2017, OCTAD 2021, GPS 2026) and rebuilt it from the published methods and primary data rather than porting the old code. The result is one Rust program with seven science modules: noise cleaning, expression prediction, reversal screening, lead optimisation by tree search, and parity with the earlier methods. Each paper's headline claim is a test target.
Where it stands
220 tests. Reconstruction, reproduction, validation and rebuild are complete (August 2026). In progress: packaging it as a self-verifying artifact, and extending the screen to neurofibromatosis (NF1) tumour signatures. Next: review by the Bin Chen lab.

Anderson-QS biology × physics

One question, asked of bacteria and of skin: when does a chemical signal get through?

The idea
Bacteria coordinate by releasing signal molecules (quorum sensing). Immune cells do the same with cytokines. Whether such a signal spreads or stays local depends on how mixed the surrounding cells are and on the shape of the space. Physics has had the mathematics for this since Anderson's 1958 work on waves in disordered material. I use it as a working model: cell diversity is the disorder, and biofilm versus shaken flask, or intact versus scratched skin, is the geometry.
Evidence
Applied to Andrea Gonzales's published work on itch signalling (IL-31, oclacitinib): six papers reproduced from the published data, 359 of 359 checks passing (March 2026). The underlying mathematics is checked against eleven papers, from Anderson 1958 to Bourgain and Kachkovskiy 2018 (417+ checks). The same graphics-card eigenvalue code serves the lattice QCD work below.
Open questions
Two predictions are waiting for a bench test. Biofilm and shaken-flask cultures should fall into different signalling regimes; the test bed is Lenski's long-term E. coli experiment, packaged to run from a USB stick. And adding tissue geometry should change which existing drugs score well for repurposing.

hotSpring plasma physics · lattice QCD

Began as reproductions of plasma simulations from Michael Murillo's group (Computational Mathematics, Science & Engineering, MSU), then extended to lattice QCD, starting from the papers of Thomas Chuna of that group.

The problem
This kind of physics normally needs a supercomputer allocation and NVIDIA's CUDA. I wanted to know whether graphics cards anyone can buy, from any maker, give the right physics.
Plasma
Nine of nine reference cases at 10,000 particles match the published Dense Plasma Properties Database, with energy drift at or below 0.002%, in 3.7 hours on one consumer card. Reproducing the original Python turned up five silent bugs in it.
Lattice QCD
SU(3) gauge theory with dynamical fermions, written as WGSL shaders over Vulkan. NVIDIA and AMD cards agree to 6 parts per million. Configurations are written in the MILC format that existing lattice codes read, and a round trip agrees to 3×10−9. The simulation runs 40 to 53 times faster than on the processor. All checks against Chuna's three papers pass.
Where it stands
A preprint is written and not yet submitted (August 2026). Not done: the comparison against Kokkos that I promised. Early figures for neuromorphic chips came from a simulator and are being re-measured on the hardware.

How I built it

  1. The paper is the specification. I read the methods, fetch the data from its original source, and write down each number the paper claims.
  2. Baseline first. I run the authors' own code where it still runs and record what it produces. This is where upstream bugs show up.
  3. Rebuild and compare. I rewrite the computation in Rust and compare it with the baseline under a named tolerance, each with its reason written down. hotSpring alone has 308 of them.
  4. Move to the graphics card and compare again, across makers, so that no result depends on one vendor's hardware.
  5. Package. The result is one static program that carries its own checks. It runs from a USB stick with no installation and no network, and exits with an error if its inputs were altered.
  6. Audit my own claims. I go back through what I have told people and mark each claim true, unverified or not done. The two gaps listed under hotSpring come from that audit.

I work with AI coding agents. I set the constraints and the acceptance checks, the agents write most of the code, and nothing is kept unless it passes. Every commit is public.

The system underneath, each part a separate program:

bearDogKeys and signing. Secrets stay inside one process and never travel between machines.
songBirdEncrypted network between machines. A machine proves it belongs with a signed certificate, not a password.
nestGateStorage in which every dataset is named by the hash of its contents.
barraCuda, toadStoolMathematics on the graphics card through WGSL and Vulkan: NVIDIA, AMD and Intel alike, at double precision.
biomeOSStarts and supervises the parts as one system on each machine.
rhizoCrypt, loamSpine, sweetGrassThe record of which data and which code produced which result.
GaiaThe self-hosted front: web, mail and a live dashboard, served from machines at home.
